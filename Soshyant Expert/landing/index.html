FAQ

Questions, answered.

Something else on your mind? Get in touch — we’re happy to go into detail.

Does Soshyant Expert train the model on our documents?
No. Documents are indexed for retrieval; the model’s weights are never changed. When you update a document, answers use the new version as soon as it’s re-indexed — no retraining, and your knowledge stays a database you control.
Does it need an internet connection?
Not in local mode. The language model, the search model and the interface files all load from the server’s own disk — no CDN, web fonts or automatic downloads. If an administrator chooses to connect a cloud model, the server then needs internet access and the question plus retrieved passages go to that provider — only after explicit approval.
Which documents can it read?
PDF (with a text layer), Word (DOCX), Excel (XLSX), plain text, Markdown and HTML. Scanned documents need OCR before they’re imported. Documents can be uploaded one by one, imported as a folder, or picked up from a watched folder.
Which languages are supported?
The interface and answers are available in English and Persian (فارسی), with a full right-to-left layout. As with any AI system, we recommend validating answer quality on a set of real questions from your own domain and language during a pilot.
Can different teams see different documents?
Yes. Administrators create access groups and choose which groups can use each document. Restricted passages are filtered on the server before search ranking and before anything reaches the model. Confidential files can be imported as “administrators only” from the very first second.
What hardware do we need?
It runs on a single Windows server or workstation. A GPU is recommended for responsive answers, and CPU-only operation is possible. The built-in hardware planner estimates GPUs, RAM and CPU cores for your number of users — and we’ll size it with you during the demo.
Is there a mobile app?
Yes — a native Android app that connects to your own server over your Wi-Fi using HTTPS and your private certificate. The model never runs on the phone, passwords aren’t stored on it, and screenshots are blocked to protect confidential content.
Where is our data stored?
Documents, conversations and accounts live in a local database on your server, and backups are written to your server too. You decide how that storage is protected and retained under your own policies.
